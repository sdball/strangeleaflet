> WELCOME TO ELIXIR!
>
> ELIXIR is a language of adventure, danger, and low cunning. In it you will explore some of the most amazing territory ever seen by mortals. No computer should be without one!

Eight pages about what makes Elixir so much fun: processes that run on their own, the BEAM that runs them, data that never changes, GenServers that hold state anyway, pattern matching, and loops that turn out to be recursion. I wrote every page as a Livebook first, so if you'd rather poke at the code than read about it, [the Livebooks are all here](https://github.com/sdball/livebooks/tree/main/books/strange-leaflet-about-elixir).
