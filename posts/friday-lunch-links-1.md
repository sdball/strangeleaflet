Hello! Here's a collection of interesting links I've found in the last week. Enjoy!

[The Little Handbook of Statistical Practice by Gerard E. Dallal, Ph.D](http://www.jerrydallal.com/LHSP/LHSP.htm) — Want to learn some Statistics?

[Text Rendering Hates You by Alexis Beingessner](https://gankra.github.io/blah/text-hates-you/) — Highlights include "you cannot correctly draw text character-by-character", "emoji broke color and style", and "anti-aliasing is hell"

[Text Editing Hates You Too by Robert Lord](https://lord.io/blog/2019/text-editing-hates-you-too/) — If you've ever dealt with rich text editing you know.

[An intern’s experience with Rust by Alexander Clarke](https://msrc-blog.microsoft.com/2019/10/16/an-interns-experience-with-rust/) — An intern at the Microsoft Security Response Center talks about learning Rust with some C++ background.

[Rising Seas Will Erase More Cities by 2050, New Research Shows](https://www.nytimes.com/interactive/2019/10/29/climate/coastal-cities-underwater.html) — Yikes.

[An Illustrated Guide to Some Useful Command Line Tools by Wesley Moore](https://www.wezm.net/technical/2019/10/useful-command-line-tools/) — This is a fantastic collection of mostly non-POSIX tools including some I hadn't even heard about yet.
